// CAPABILITY

能力矩阵

三个入口，把「真实模型」这件事查清楚。

◈

轮次徽标

每条完成的回复尾部自动出现 ⚙ deepseek-v4.1-flash 这样的芯片，悬停查看详情。按轮次渲染，因为同一会话可能在不同轮次切换上游。

⌘

real_model 工具

直接问 AI：「用 real_model 查一下这轮用的什么模型」。支持 session / cwd / last / summaryOnly 参数，返回按模型聚合的计数。

▤

日志直读

数据源是 session.vN.jsonl.zstd 里的 responseModel 字段——供应商真正返回的模型名，比界面顶层的路由组标签可靠得多。

// ARCHITECTURE

数据链路

从一条日志，到你眼前的那枚芯片。

  • 01逐帧解压：多帧 zstd 需顺序扫描 0x184D2A50（skippable）与 0xFD2FB528（数据帧）。
  • 02多数投票：一轮可能有多步，按该轮各步的真实模型投票得出代表值。
  • 03精确路由：GET /dsh-real-model/turn-model?turn=N&session=<id>（DSH 只支持 exact 路由）。
// DEPLOY

安装

两步上线，重启后生效。

01 打包

pnpm pack

在插件源码目录执行，得到 .tgz。

02 安装并重启

plugin_manager install_bundle <tarball>

也可在 设置 → 插件 中安装 tarball，然后重启 DSH。

!
升级必须升版本号。 DSH 按 generation 路径缓存已加载的 ESM，同版本重装不会生效——改了代码记得改 package.json 的 version。
